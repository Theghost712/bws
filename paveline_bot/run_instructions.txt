Step-by-Step Run Instructions

1. Environment Setup
   - Navigate to paveline_bot directory: cd paveline_bot
   - Install dependencies: pip install -r requirements.txt
   - Copy .env.example to .env: cp .env.example .env

2. Telegram Bot Setup
   - Open Telegram and search for @BotFather
   - Send /newbot and follow prompts
   - Copy the token to TELEGRAM_TOKEN in .env
   - Optional: Get your user ID from @userinfobot and add to ADMIN_IDS

3. Configure AI Provider (Choose one)
   Option A: Ollama (Free, Offline, Recommended for local)
     - Install Ollama: https://ollama.ai/
     - Pull a model: ollama pull llama3.2
     - Set AI_PROVIDER=ollama in .env (default)

   Option B: Google Gemini (Free tier)
     - Get key from https://aistudio.google.com/apikey
     - Set AI_PROVIDER=gemini, GEMINI_API_KEY in .env

   Option C: Groq (Free tier)
     - Get key from https://console.groq.com/keys
     - Set AI_PROVIDER=groq, GROQ_API_KEY in .env

   Option D: OpenRouter (Free models)
     - Get key from https://openrouter.ai/keys
     - Set AI_PROVIDER=openrouter, OPENROUTER_API_KEY in .env

4. Configure Scheduling & Settings
   - Set SEND_TIME (default 07:00)
   - Set TIMEZONE (default Africa/Dar_es_Salaam)
   - Adjust other settings as needed

5. Run the Bot
   - For testing: DRY_RUN=true python main.py
   - For production: python main.py

6. Deployment Options (24/7)
   - systemd: Create service file for your OS
   - Docker: Build image with included Dockerfile (if needed)
   - Free hosts: Railway, Render, etc. (note: some require persistent disk)

7. Verify Installation
   - Run tests: python -m pytest -v
   - Check database is created: paveline.db should appear
   - Cards saved to output/ directory
